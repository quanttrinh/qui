Generate React 19+, Solid, and Preact JSX declarations with `@stencil/types-output-target` and expose them as `@quanttrinh/qui/types/react`, `@quanttrinh/qui/types/solid`, and `@quanttrinh/qui/types/preact`. The package root also re-exports the generated component prop and custom event types so the framework declarations resolve from one entry point. The Preact declarations require Preact 10.28 or newer.
